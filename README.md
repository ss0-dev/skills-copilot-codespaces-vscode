# Daily Routine Tracker

A simple website to track daily study habits, physical activity, and nutrition, with calendar-style date selection and reminders.

## Usage

1. Open `/home/runner/work/skills-copilot-codespaces-vscode/skills-copilot-codespaces-vscode/index.html` in a browser.
2. Select a date and save your daily routine metrics.
3. Add reminders for upcoming tasks.

Data is stored locally in your browser using `localStorage`.
